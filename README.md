
# DevHub Dashboard

A modern analytics dashboard built with Flutter.

## Features

- Active Users: 1,240
- Repositories: 85
- Pull Requests: 32
- Server Uptime: 99.9%

## Technologies

- Flutter
- Dart
- Material Design

## Getting Started

1. Install Flutter.
2. Run `flutter pub get`.
3. Run `flutter run`.

## Project Structure

- `lib/main.dart` - Application entry point and dashboard UI.
- `pubspec.yaml` - Project configuration and dependencies.
